you can turn on debug return code messages in nimconfig.h, just uncomment what you want to see in this area:
https://github.com/h2zero/NimBLE-Arduino/blob/4fb60b8433a4bfb15fefe6fe128d21712f5fce56/src/nimconfig.h#L79

The disconnect codes you see there are:
574 = Connection Failed to be Established
520 = Connection Timeout
546 = LMP Response Timeout / LL Response Timeout

Looks like you're connection is weak, you could try bumping up the power level to compensate.
You can do this by calling:

 NimBLEDevice::setPower(ESP_PWR_LVL_P9);
That will set them to max power.
